# 🚆 RailBook – Train Reservation System

**RailBook** is a Java-based Train Reservation System developed using Java Swing. It provides a graphical user interface for managing train reservations and demonstrates important Object-Oriented Programming (OOP) concepts, including inheritance, `ArrayList`, and file handling.

🔗 **GitHub Repository:** https://github.com/malisadashiv25-png/RailBook-Train-Reservation-System

## 📌 Project Overview

RailBook aims to simplify train reservation operations through a desktop application. It uses Java Swing to provide a graphical interface and file handling to store and retrieve application data.

The project is designed to demonstrate how Java programming concepts can be applied to a real-world reservation management problem.

## ✨ Features

- **Graphical User Interface:** Interact with the application using Java Swing.
- **Train Reservation:** Manage train booking operations.
- **Passenger Management:** Store and retrieve user information.
- **PNR Receipt:** Maintain reservation receipt information.
- **File Handling:** Store application data in text files.
- **ArrayList:** Manage collections of objects dynamically.
- **Inheritance:** Apply OOP concepts to organize and reuse code.
- **Reservation Records:** Maintain booking information for later access.

## ⚙️ Requirements

Before running the project, ensure you have:

- Java Development Kit (JDK) installed.
- A Java-compatible IDE, such as IntelliJ IDEA, Eclipse, or VS Code.
- Git installed (optional, for cloning the repository).

## 🚀 Installation and Setup

### 1. Clone the repository

Open your terminal or command prompt and execute:

```bash
git clone https://github.com/malisadashiv25-png/RailBook-Train-Reservation-System.git
```

### 2. Navigate to the project folder

```bash
cd RailBook-Train-Reservation-System
```

### 3. Open the project

Open the folder in your preferred Java IDE and locate the Java source files inside the `src` directory.

### 4. Compile and run

Compile and run the main Java class containing the `main()` method. If using an IDE, open that class and click **Run**.

If the application requires a particular working directory for its text files, run it from the project root so the data files can be accessed correctly.

**Note:** The exact main class and launch command depend on the source files in the repository.

## 💻 How It Works

1. Launch the Java Swing application.
2. Use the graphical interface to access the available reservation operations.
3. Enter the required user or booking information.
4. Process reservation-related operations supported by the application.
5. Store and retrieve information using local text files.
6. Refer to the generated PNR receipt and saved reservation records where applicable.
